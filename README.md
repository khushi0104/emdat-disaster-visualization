# EM-DAT Disaster Visualization Dashboard

This project is an interactive Streamlit dashboard that explores global disaster trends using the EM-DAT dataset.

## Features

- Disaster trends over time
- Geographic impact view
- Disaster type comparison
- Sidebar filters
- Key insights tab
- Design rationale tab

## Tools Used

- Python
- Streamlit
- Pandas
- Plotly

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
